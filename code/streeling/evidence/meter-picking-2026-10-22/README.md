# Meter grouping, anchored cycles and guitar picking phase

This packet supports MCL006, WML006 and GTR007. It contains authored fixed score/group/picking calculations and actual primary-source reading. It is not a live score conversion, performed rhythm, implemented phase planner, production change or new runnable lab.

## Contents and interpretations

- `production-plan.md` records predictions and evidence gates before calculation.
- `primary-readback.json` binds six anonymously fetched GA files to commit `76efbffd5af82b46c3146957a6bd4504008eeb89`, with exact immutable local Git byte equality. Source branches predict selected outcomes; none was freshly executed.
- `primary-reading.json` records actual reading of eight W3C MusicXML4 reference bodies. Additive/mixed-denominator time signatures, metronome units, score divisions and up/down-stroke symbols are specification facts, not project conformance results.
- `meter-units.json` retains six exact complete-bar cases with constant declared rates and 24 divisions per quarter. Seven eighths span 84 score divisions; 2+2+3 eighth grouping and 2/4+3/8 share duration but not component boundaries. These score divisions are not automatically a MIDI tick resolution or an observed playback clock.
- `anchored-cycles.json` retains A=(2,2,3), B=(3,2,2), C=(2,3,2), seven pulse shifts, three group-start rebases, all 35 three-onset subsets of seven labelled pulses and their five rotation classes. Empty/full sets are negative controls. These are authored combinatorics, not five cultural categories or a recorded accent distribution.
- `picking-phase.json` retains five 28-row traces and 29 complete phase states: all attacks, intentional per-bar reset, repeated rest with attack-driven counting, the same rest with a pulse clock, and a continuation at absolute pulse 7. Pick/bar phases return after 14 pulses; adding an independent four-pulse marker gives a first complete return after 28. Direction is not accent, difficulty or a preferred technique.
- `source-observations.json` labels static integer-beats, first-pair, metadata, unsupported-technical-sign and unpopulated-tie boundaries. It keeps direction-capable types distinct from one selected down-stroke case and from a tested binary format or cross-bar planner.
- `data-audit.json` independently recalculates all fixed rows and source provenance. `content-audit.json` records completed independent AI review when present.
- `learner-task.md` and `reviewer-rubric.json` prepare a transfer exercise. All actual human and participant outcomes remain null until observed.

## Publication and further evidence
