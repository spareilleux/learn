# Color and data-texture teaching evidence

PHY009, VC010 and COG006 cover linear/display coordinates, packed channel contracts and pixel-versus-appearance questions. Each has five corrected exercises in English, French and Spanish. This is prose and fixed teaching evidence, not a production shader/importer correction or runnable lab.

## Inputs and observations

- `production-plan.md` records scope and predictions before calculation or image generation.
- `primary-readback.json` binds four public GA text files and two existing public concrete PNGs at commit 76efbffd5af82b46c3146957a6bd4504008eeb89, anonymously retrieved and byte-matched to immutable Git objects. The dirty GA working tree was not used or edited.

- `official-links.json` separates URL transport from actual primary-source reading. The dated W3C draft, versioned Godot/Blender guidance and primary perception paper have different evidence roles. Unavailable routes are not counted as successful content reads.
