# DV-008 learner transfer task v2 — historical model and current migration

Give this sheet to a learner before showing the DV-008 lesson or its answer blocks. The four cards below are **synthetic**. They are not current Streeling modules or a live public readback.

For this historical classroom model, an **exact public readback** requires anonymous HTTP 200, a matching index source link, a matching module source link, and a matching rendered heading for the same Demerzel SHA. “All gates” additionally requires authored source and a human review approved for that source version.

## Tasks

1. For each card, mark exact public readback and all gates as yes or no. Explain one case where a page's HTTP 200 and matching heading are insufficient.
2. Count authored source, approved review, exact public readback, and all gates across the four cards. State what the denominator is for this classroom count.
3. Suppose the Demerzel progress script reports 120 of 525 authored core courses and zero review approvals at a pinned revision, but no exhaustive public sweep has run. Write a two-sentence dashboard caption that treats the public count correctly.
4. Pick U and V. Give one concrete evidence-producing next action for each, preserving the exact source revision.
5. The first learner report says W is “complete” because it has three green labels. Name one observable fact outside this toy table that would overturn the real-world completion claim for a Streeling course.

6. The course source has now moved to Learn. A deployed page links to Learn `main` and its heading matches. Does that alone identify the reviewed source version? State the evidence you would gather before reporting current course completion, and explain why the historical readback script cannot be used unchanged as that proof.
