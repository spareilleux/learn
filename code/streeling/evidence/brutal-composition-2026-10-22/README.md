## Boundaries that the courses preserve

Scene descriptions, block instances, boxes and declared box triangles are different units. The transform convention uses row vectors, local times parent, and scale before yaw before translation. Fresh seeded generation is deterministic for the checked requests; a context with mutable random state does not prove every possible block function is mathematically pure or total. Repeated bytes or a scene hash do not establish a rendered image or performance.

Standard generation limits are depth 8, instances 4096 and boxes 20000. The root is depth 0. The guard may count one attempted box beyond the limit while retaining no more than the allowed placed boxes; this does not give the intended complete size of a refused scene. CPU acceptance is a boundary result, not GPU safety or coexistence certification.

The M2 report records a severe adjacent-view drop. M3 controls also varied without HallSlice, and the public evaluation retains an inconclusive verdict. Different frame-time endpoints and thresholds must remain visible. A requested DLSS flag is not observed feature activation or measured quality/performance.
