# Intonation, interference and pitch discrimination

This packet supports WML004, PHY007 and COG004 in English, French and Spanish. It contains fixed evidence, original oscillator audio, an original scientific figure and prepared source-assisted tasks. It delivers no new production or teaching-lab program.

## Evidence map

- experiment-plan.md records predictions before numerical analysis.
- primary-readback.json binds eight anonymously fetched public GA files byte-for-byte to commit dc2e74cbd992a298f67efb928b5b3754615e1924. The mutable primary checkout was not used as the teaching snapshot.
- ga-intervals-probe.json records the actual C interval-name response. Its runtime source revision and tuning behavior are unattested.
- intonation.json contains selected catalog fields, reference formulas and an explicitly authored nearest-step projection. The 5:4 example is not a prescribed intonation for Rast or another tradition. Proposed retained-value examples are advisory, not an implemented schema.
- beats.json records constant-amplitude cosine interference, sample windows and the equal-frequency control. These are constructed signals, not a new GA engine run or a diagnosis of a physical guitar.
- audio-assets.json binds three original mono PCM16 WAVs, their fades, numerical RMS matching and quantization checks. The one-second single tones serve a proposed sequential task; the four-second mixture illustrates simultaneous interference. No asset was played or listened to here. Numerical RMS matching is not measured perceptual loudness equality.
- two-tone-envelope.png plots the untapered mathematical model. It is not a plot of the faded, quantized WAV.
- synthetic-trials.json is a public authored answer key and synthetic response trace, with exact binomial and best-of-eight calculations. It is not an administered randomized or blinded protocol or participant result.
- execution.json records installed analysis versions and the temporary analysis script's hash. The first temporary run failed on an incorrect stat size call after partial numerical output; the corrected complete run produced these assets and records. No dependency installation occurred.
- learner-task.md and reviewer-rubric.json prepare three tasks and fifteen criteria. Outcomes remain null.
- data-audit.json and content-audit.json bind independent AI checks of their stated inputs. They are not human, musician, fluent-language or participant approval.
