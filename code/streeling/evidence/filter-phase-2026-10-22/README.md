This packet supports GAS007, AUD008 and INF008. It contains fixed authored mathematical examples and pinned source/test interpretation. It contains no new engine/audio capture, calibrated physical body, listener result, production adapter or runnable lab.

## Inputs and calculations

- `production-plan.md` records the production scope and gates. It was written after initial calculation/drafting; it does not claim advance preregistration.
- `primary-readback.json` binds five public GA source/test files and two IX source files to anonymous downloads and immutable local Git objects. `primary-reading.json` identifies the actual mathematical and bridge-model bodies read.
- `body-response.json` evaluates five sections at 44100 Hz using ideal binary64 arithmetic on the pinned decimal parameters. It keeps recurrence versus denominator signs, exact isolated maxima, finite impulse-sum comparisons and ten complex bank/dry responses. The 110/240 Hz pole-frequency parameters yield isolated DC maxima in this mathematical model. These are not full-engine or physical measurements, nor bit-exact Rust f32 results.
- `paired-transfer.json` retains two periodic N8 experiments with the same two-tap filter and differing excitation strengths. It keeps input/output samples and complex transforms, an undefined unexcited-bin ratio, a weak-input/output-noise example and a separate phase-pi/4 zero-initial linear convolution truncated from nine samples to eight. The between-trial transfer ratio is unity; the filter's transfer at the selected bin is a different complex quantity.
- `phase-pair.json` retains two unequal reversed two-tap responses, equal magnitudes but distinct phases, full complex inverse reconstructions, a zero-phase reconstruction assumption, energy centroids and all eight circular-shift controls. Equal magnitude is not waveform identity. The example does not establish a universal impossibility theorem for overlapping constrained spectrogram phase retrieval.
- `source-observations.json` distinguishes the body's linear stage from downstream reverb/nonlinear output, IX complex spectra from scalar projections, and GA canonical prime-form data from actual-chroma phase alignment. Source test text is not a fresh test run.
