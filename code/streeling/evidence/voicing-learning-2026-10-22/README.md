## Teaching and review boundaries

Computed span, physical fret distance and player comfort are different observations. BarreRequired and IsFullBarre remain different predicates. A clean progression report is not a musical-quality judgment, especially when a voice changes strings. The six-trial confidence table is synthetic; neither its Brier score nor the historical bad marker proves a learning outcome. DADGAD's table establishes note instructions, while the attributed cultural prose still requires relevant musical and cultural evidence. Literal term matching is not fluent-language review.
