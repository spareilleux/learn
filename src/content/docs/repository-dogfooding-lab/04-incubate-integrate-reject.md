Incubation is not a euphemism for adoption. It is a bounded environment where a candidate competes with the current solution.

## Promotion gates

| Transition | Gate |
|---|---|
| discovered → experimenting | Pain and falsifiable hypothesis are evidenced; simpler alternative recorded |
| experimenting → incubating | Baseline, reproducible result and independent review exist |
| incubating → integrating | Tracer bullet wins on predeclared metrics and has rollback |
| integrating → adopted | Repository checks pass, accountable authority accepts, operational evidence remains healthy |
| any → rejected | Falsifier hit, no useful seam, or simpler alternative wins |

## Integration principles

- integrate one vertical tracer bullet, not a horizontal platform;
- preserve existing contracts until replacement evidence exists;
- pin versions and exact revisions in the experiment;
- separate author, reviewer and merge authority for material changes;
- retain the rejection and its evidence.

For the current Jev opportunity, even a good calibration only permits the next bounded A/B. It does not authorize provider routing in GA, Gaia or Demerzel.
