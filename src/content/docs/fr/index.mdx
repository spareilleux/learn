## Pourquoi ce site

J'écris ces cours d'abord pour moi : expliquer un sujet est le meilleur moyen de vérifier qu'on l'a compris.
Ils sont publics pour que d'autres puissent en profiter — et me corriger.

	<Card title="Mission" icon="rocket">
