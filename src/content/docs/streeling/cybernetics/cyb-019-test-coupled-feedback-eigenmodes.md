GA and IX agents can each reduce their local deviation while triggering extra corrective work in the other repository. Reviewing each local multiplier in isolation can miss this interaction. The question is whether the joint update shrinks every mode, including a mode in which both deviations rise together. Define the coupling explicitly before applying a scalar convergence rule to a multi-agent workflow.

Use a symmetric transition with identical diagonal terms and a cross term in each off-diagonal position. Adding the coordinate equations gives a common-mode multiplier; subtracting them gives an opposing-mode multiplier. These calculations expose the eigenvectors directly, so a general numerical eigensolver is unnecessary. A diagonal entry smaller than unity describes only the system with its neighbour held fixed.

In the fixed case the common mode grows while the opposing mode shrinks and alternates. Starting with equal positive coordinates excites the growing mode, making a short exact trajectory a visible witness. The control reduces the cross term and shrinks both modes. Checking only the displayed starting trajectory would still be weaker than checking both multipliers, because another starting state could excite the other mode.

The earlier convergence lesson supplies error dynamics for a diagonal material calculation. This lesson changes the dependency structure, rather than retuning that example. Harvard’s discrete-time criterion applies to the diagonalizable matrix here. Actual agent handoffs can be delayed, nonlinear and discontinuous; their observed local improvements do not identify these coefficients. A future dogfood study needs aligned revision-bound changes and a measured transition before this algebra could inform coordination.

### Exercise 1

Find both mode multipliers.

<details><summary>Answer 1</summary>

They are `1.25` and `-0.25`; the spectral radius is `1.25`. The matrix is unstable despite diagonal entries `0.5`.

</details>

### Exercise 2

Trace the common-mode witness.

<details><summary>Answer 2</summary>

Starting from `[1,1]`, the final vector after `3` steps is `[1.953125,1.953125]`. Each step amplifies the shared deviation.

</details>

### Exercise 3

Apply the reduced-coupling control.

<details><summary>Answer 3</summary>

The eigenvalues become `[0.75,0.25]`, both strictly inside the unit circle. The final common-mode vector is `[0.421875,0.421875]`; stability is `true`.

</details>

### Exercise 4

Can a shrinking opposing trajectory certify stability?

<details><summary>Answer 4</summary>

No. It excites only its own mode. The unexcited common mode can still grow; check every eigenmode under the declared linear model.

</details>

### Exercise 5

What would reject the proposed real coordination rule?

<details><summary>Answer 5</summary>

A measured transition outside the assumed model, an amplifying mode, or unacceptable boundary behaviour. Scalar local progress alone cannot validate the coupled rule.

</details>
