An agent coordinator can observe a queue state without having actions that reach a requested endpoint within a deadline. Even full linear controllability rank does not settle that operational question when commands are bounded or discrete. The baseline mathematics course already teaches the double-integrator rank test. This lesson adds a different operation: enumerate permitted finite command sequences, test the specific endpoint and minimize a declared command-energy cost.

Expand the state recurrence in input-time order. Earlier commands undergo more transitions before the endpoint, so their columns differ from those of later commands. Keep that linear reachability matrix as a diagnostic, but enforce the allowed action alphabet during enumeration. Propagate every candidate through the recurrence, retain only exact target matches and compare sums of squared commands. This finite search gives a reproducible optimum for the declared alphabet; it is not a continuous optimal-control solver.

The fixed horizon permits an early command to accumulate enough position change without exceeding its allowed magnitude. The shorter-horizon control retains full rank yet requires an unrestricted command outside the allowed alphabet. No bounded sequence succeeds. More telemetry does not create a missing admissible action, and a rank certificate must not override the explicit refusal. A future control DSL should retain the horizon, action domain and empty-feasible-set result before any scheduler can treat a target as executable.

## Corrected exercises

### Exercise 1

Why keep command-time order?

> **Answer:** The fixed matrix is `[A*A*B,A*B,B]` for `[u0,u1,u2]`. Earlier commands propagate longer, so equal command magnitudes can have different endpoint effects.

### Exercise 2

Find the bounded fixed optimum.

> **Answer:** The matrix `[[2,1,0],[1,1,1]]` has rank `2`. The sole feasible sequence `[1,0,0]` reaches `[2,1]` with squared-command energy `1`.

### Exercise 3

Why does full rank not rescue the shorter-horizon control?

> **Answer:** At horizon `2`, the matrix still has rank `2`, but its unrestricted solution `[2,-1]` uses forbidden action `2`. The feasible sequence set is empty; minimum energy is `null`.
