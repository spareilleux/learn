## Project question

A low-poly sculpture can meet a triangle budget and still lose a curved rim that identifies the piece. This lesson puts an explicit geometric tolerance beside a simplification budget. We replace an ideal circular profile with an inscribed regular polygon and calculate the maximum radial gap along each chord. The model concerns a deliberately simple section, so its accuracy is inspectable without running Blender.

## Interpret the model

Each segment spans an equal central angle. At its midpoint, the chord lies inside the circle; subtract its distance from the center from the radius. This sagitta is a length, while segment count is dimensionless. The perimeter calculation answers another question and cannot substitute for the local error bound. A doubled segment count need not halve radial error. The chosen tolerance belongs to this authored feature and unit system. A real sculpture may have varying curvature, creases or noncircular sections, where a regular-polygon construction does not provide a global guarantee.

The direct baseline is a labelled sketch and a hand calculation with the answer panels closed. Preserve intermediate values and units, then apply the changed input in the negative control. A disagreement is useful evidence: locate whether it comes from the definition, arithmetic, representation or intended task before changing the model. Agreement on the main case alone does not establish a universal rule. These finite examples deliberately expose an assumption that a smooth preview could conceal.
