## The project question

A practice agent addresses a note as a bar and beat but treats a pickup as a full bar. Every later absolute time then shifts. This lesson preserves written measure identity and actual duration separately, using a single-voice authored score. It does not parse a score or infer an expressive performance from notation.

## 1. Exercise 1

Use measure labels `0`, `1`, `2`, with actual quarter durations `[1,4,4]`. The first is an authored pickup. Labels are identifiers; they are not a multiplication rule for duration. Prefix sums give starts `[0,1,5]` in quarter-note units from the excerpt origin.

At which absolute quarter positions do the measures start?

> **Answer.** They start at `[0,1,5]`; the pickup contributes 1 quarter, not 4.

## 2. Exercise 2

Place an event at zero-based local quarter offset 1 in measure 2. Its absolute coordinate is `5+1=6`. Keeping the zero-based convention explicit avoids confusing an offset with the displayed beat number. The local address remains attached to the written measure even when another excerpt origin is chosen.

Give the absolute event coordinate.

> **Answer.** It is 6 quarters from this excerpt origin; retain measure label 2 and local offset 1 as well.

## 3. Exercise 3

At constant quarter-note rate 120, each quarter lasts .5 seconds. The event at coordinate 6 therefore occurs at 3 seconds. A tempo map would require the prerequisite's interval integration instead. The pickup correction and tempo integration solve different missing-context problems and must both be retained when both are present.

Convert this event to seconds under the stated rate.

> **Answer.** `6*60/120=3` seconds; no expressive onset or recorded latency was measured.

## 4. Exercise 4

As a negative control, replace the pickup's actual duration with nominal 4. Starts become `[0,4,8]`, and the same local address maps to 9 quarters. The error is 3 quarters, or 1.5 seconds here. The address text can look unchanged while the chosen duration model has moved the event.

What offset error does the full-pickup shortcut create?

> **Answer.** It adds 3 quarters, equal to 1.5 seconds at the declared tempo.

## 5. Exercise 5

MusicXML permits textual measure identifiers and describes pickup-related implicit numbering. Read that definition alongside the retained complete-bar prerequisite. Neither reading makes this toy prefix sum a general importer: chords, backup, forward, voices and changing divisions require explicit treatment. A source-assisted report should retain both address and accumulated coordinate.

Does a measure number alone determine elapsed time?

> **Answer.** No. Actual durations, local offset, origin and tempo context are required; numbering is insufficient.
