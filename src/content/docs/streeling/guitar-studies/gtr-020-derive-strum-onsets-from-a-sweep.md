A chord contains several sounding notes, but a plectrum reaches their strings at different times. A GA exercise that schedules them simultaneously may preserve pitches while discarding its requested strum. We convert a declared sweep through string coordinates into onset times. The new task keeps spatial travel through muted strings instead of treating the sounding list as a compressed set of adjacent strings.

Use a constant sweep speed and an origin at the extreme string in the chosen direction. Compute each crossing time from distance divided by speed, then retain events only for sounding strings. Muting removes a pitched event; it does not remove that string’s coordinate from the instrument. Rebuilding equal spacing from the shortened sounding list would silently shorten the travel path.

The reversed control traverses the same geometry and has the same onset spread, yet the interior note enters at a different time relative to the first sounding note. A spread-only report therefore loses information about attack order and spacing. Store the ordered event list if the practice instruction needs that detail. The retained occupancy material distinguishes sounding support from technique; it does not measure this sweep. Real plectrum contact, bending, spacing variation and acoustic response can shift observed attacks. The authored map is a manual planning baseline for a proposed articulation handoff. It is not evidence of synchronized playback, a recording or a player executing the planned motion.

## Assumptions and evidence limits

Assume fixed parallel string coordinates, positive constant sweep speed and instantaneous excitation at each crossing. Muted crossings have no pitched event. Real pick compliance and acoustic latency remain unmeasured.

### Exercise 1

Compute the sounding crossing times in the main direction.

<details><summary>Answer 1</summary>

Use the original string coordinates and speed; the skipped muted coordinates still contribute to travel distance.

</details>

### Exercise 2

Why must a muted string remain in the geometry?

<details><summary>Answer 2</summary>

It removes an excitation event but does not move the other strings closer together.

</details>

### Exercise 3

What does reversing the sweep preserve?

<details><summary>Answer 3</summary>

It preserves the extreme-to-extreme travel time and the total onset spread in this symmetric origin convention.

</details>

### Exercise 4

What does the reversed control change?

<details><summary>Answer 4</summary>

It reverses event order and changes the interior event’s delay relative to the first onset.

</details>

### Exercise 5

What falsifies a spread-only articulation handoff?

<details><summary>Answer 5</summary>

The same-spread control has a different ordered onset list, so spread alone cannot reconstruct the requested articulation.

</details>
