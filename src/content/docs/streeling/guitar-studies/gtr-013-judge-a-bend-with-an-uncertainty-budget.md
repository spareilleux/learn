A tuner display near a target does not automatically establish that a bend met a practice criterion. The estimate may have uncertainty, and the target itself needs a reference. GA can help a guitarist state these quantities before offering feedback. This lesson uses an authored cent estimate with a bounded error interval. It adds a decision rule to the prerequisite's frequency representation, while leaving actual pitch tracking and performance unobserved.

## Read the retained evidence

Read the retained intonation packet's frequency reference, constructed cent offsets and source-boundary notes. Its values are authored calculations, not a bend recording. NIST defines a musical cent through a frequency ratio. We use that ratio only; no listening threshold is imported. The acceptance tolerance below is a local teaching choice and must not be presented as a universal standard of good playing.

### Exercise 1

Use base frequency `110 Hz` and target rise `2` semitones. The target interval is `200` cents, and target frequency is `110*2^(2/12) Hz`. A fixed reference makes this reproducible. Naming the target note without the reference would hide whether the task compares equal-tempered pitch, another tuning or an expressive destination.

State the target in cents and as a frequency expression.

<details><summary>Answer 1</summary>

The target is `200` cents above the base, or `110*2^(2/12) Hz`. This is the declared equal-tempered target, not a measured bend.

</details>

### Exercise 2

The authored estimator reports `195` cents with bounded uncertainty `3` cents. Signed point error is `195-200=-5` cents. Its sign says the estimated bend is flat relative to the target. The uncertainty is not an extra pitch shift to apply to the guitar; it describes the range of values this model treats as compatible with the estimate.

What is the signed point error?

<details><summary>Answer 2</summary>

It is `-5` cents. The negative sign indicates a lower estimate than the target; it does not by itself establish failure or identify the true error exactly.

</details>

### Exercise 3

Set an inclusive tolerance of `10` cents. Our conservative rule requires the entire uncertainty interval to fit inside tolerance, using `worst_abs_error=abs(error)+uncertainty`. Here the worst magnitude is `8` cents, so the modeled claim is established. The rule does not assign a probability because the uncertainty was supplied as a bound, not a distribution.

Does the main case establish the chosen criterion?

<details><summary>Answer 3</summary>

Yes: `8` cents is at most `10` cents. This accepts the authored bounded case under the rule; it does not certify a learner's actual take.

</details>

### Exercise 4

The negative control changes only the estimated bend to `191` cents. Point error is `-9` cents, still inside the tolerance, but the worst magnitude becomes `12` cents. A point-only display would call this acceptable, while the declared interval rule cannot establish it. Preserve the difference between a rejected claim of certainty and evidence that the performance definitely failed.

What decision follows for the control?

<details><summary>Answer 4</summary>

The criterion is not established: the worst error is `12` cents, above `10`. This does not prove the true bend was outside tolerance; the supplied uncertainty leaves that unresolved.

</details>

### Exercise 5

A real task must define when the bend is assessed: attack, sustained plateau or release can yield different answers. It also needs an estimator whose uncertainty has evidence for that signal and window. An agent should retain a requested target, time support, estimate, uncertainty and decision rule rather than silently using a rounded note label as proof.

What would falsify the claim that the feedback is uncertainty-aware?

<details><summary>Answer 5</summary>

A decision that accepts the control solely because its point error is within tolerance would contradict the stated rule. Runtime tracking fidelity and musical expressiveness require separate observations.

</details>
