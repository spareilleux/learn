## Project question and deliverable

An agent can sort candidates correctly by a score that fails the intended musical relation. Build a two-candidate ranking, compare it with an independently enumerated reference, and write a bounded decision. This exercise concerns the pinned [GA distance class](https://github.com/GuitarAlchemist/ga/blob/dc2e74cbd992a298f67efb928b5b3754615e1924/Common/GA.Domain.Services/Atonal/VoiceLeadingSpace.cs). It does not run GA's nearest-neighbor index or user interface.

The distinction from [MUS-022](../../music/mus-022-grothendieck-deltas-icv-distance/) matters: comparing interval-content vectors answers a different question from matching pitches between voices. Here the declared objective allows octave changes and target permutations, while preserving pitch-class content for a zero-cost match. Transposition and inversion equivalence stay disabled.

## 1. Predict the ranking before sorting

Use query `[60,63,65]` and two targets:

| Candidate | Registered pitches | Pitch-class content |
|---|---|---|
| Same | 60, 65, 75 | 0, 5, 3 |
| Near | 60, 63, 66 | 0, 3, 6 |

Same contains exactly the query's pitch-class multiset, so an exhaustive assignment can cost 0. Near changes the last class by one semitone; its best assignment costs 1. These are predictions from the declared objective, independent of the source's cyclic search.

### Practice exercise 1

Write a zero-cost target assignment for Same and a cost-1 assignment for Near.

> **Answer:** Same: match `[60,63,65]` with `[60,75,65]`, for circular costs 0, 0 and 0. Near: match `[60,63,65]` with `[60,63,66]`, for costs 0, 0 and 1. These give upper bounds; exhaustive enumeration in the retained lab confirms the minima for these cases.

## 2. Compare two actual calculation paths

The [standalone lab](https://github.com/spareilleux/learn/tree/codex/streeling-craft-transfer-20261022/code/streeling/voice-leading) compiles unchanged GA source plus a compile-only annotation adapter. It also enumerates all indexed permutations independently for these small arrays. The [retained results](https://github.com/spareilleux/learn/blob/codex/streeling-craft-transfer-20261022/code/streeling/evidence/voice-leading-2026-10-22/native-results.json) give:

| Candidate | Native cost | Exhaustive cost |
|---|---:|---:|
| Same | 4 | 0 |
| Near | 1 | 1 |

Sorting each column ascending reverses the two-candidate order. The native calculation ranks Near before Same; the reference ranks Same before Near. This is a constructed local ranking. A consumer that normalizes its inputs differently may not encounter this case. No behavior of the upstream search pipeline is inferred from this table alone.

### Practice exercise 2

Would replacing the sorting algorithm fix this disagreement?

> **Answer:** No. Both columns are sorted correctly according to their values. The disagreement comes from the computed cost of Same under the intended equivalence contract. Investigate the representation and assignment search before changing the rank sorter.

## 3. Test a representation change without calling it a fix

Reducing this query and Same modulo 12 gives `[0,3,5]` and `[0,5,3]`. The unchanged native class then returns 0. This transformation removes the particular registered-order obstruction in the example. It has not patched the production method or proved a theorem about every input.

It also discards registered octaves. If a consumer needs a melody's register, retain the original pitches separately. If it needs an actual correspondence, retain a witness as in [MUS-016](../../music/mus-016-recover-voice-correspondence/). A normalized scalar cannot reconstruct the discarded information.

### Practice exercise 3

Can the normalized zero be used to conclude that the registered motion of the second labeled voice is 0?

> **Answer:** No. In the declared witness, that voice goes from 63 to 75, moving 12 semitones. The zero belongs to the octave-equivalent comparison. Keep the original registered pitches if that movement matters to the task.

## 4. Require an independent reference to catch errors

The lab fixes its expectations before implementation. The retained upstream seven-voice fixture costs 8 in both paths; the exhaustive reference visits 5,040 indexed permutations. Reproducing this fixture alone would miss the smaller registered counterexample. One passing example cannot establish the general equivalence claim.

The lab's negative control deliberately replaced the oracle with the native result in a scratch copy. It was rejected by `oracle_zero_known_case`: expected 0, actual 4. This confirms that the retained gate can detect that specific loss of independence. It does not measure broad mutation coverage or learner success. The [control receipt](https://github.com/spareilleux/learn/blob/codex/streeling-craft-transfer-20261022/code/streeling/evidence/voice-leading-2026-10-22/negative-controls.json) retains the boundary.

Rerun through installed [Node.js](https://nodejs.org/api/cli.html) and [.NET](https://learn.microsoft.com/dotnet/core/tools/dotnet-build) using MUS-015's command. Inspect both the characterization verdict and the separate original-equivalence verdict. Windows is the only assessed platform.

### Practice exercise 4

Why would using the native cyclic minimum as the “expected exhaustive answer” weaken the exercise?

> **Answer:** Both paths would inherit the same search restriction. Agreement could then hide the missing zero-cost permutation. Independent hand arithmetic and exhaustive enumeration supply evidence the source's own result cannot provide about itself.

## 5. Turn the experiment into an agent decision

Write a handoff with the source revision, candidate arrays, equivalence contract, both costs, both orders and the limited normalization observation. For this comparison, do not accept the native score as satisfying the intended equivalence. A production fix needs its own implementation and regression evidence; the lab has not supplied that fix. The [learner packet](https://github.com/spareilleux/learn/blob/codex/streeling-craft-transfer-20261022/code/streeling/evidence/voice-leading-2026-10-22/learner-task.md) separates factual source-assisted checking, human review and an eventual playing trial.

### Practice exercise 5

An agent proposes automatically normalizing every consumer's input. What must it establish first?

> **Answer:** Identify each consumer's comparison contract and whether registered pitch, voice identity or string assignment must survive. Then verify the proposed behavior against those contracts with independent cases. This example supports a specific counterexample and a specific transformed input; it does not authorize a universal normalization policy.
