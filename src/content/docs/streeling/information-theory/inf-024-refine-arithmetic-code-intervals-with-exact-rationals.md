An agent artifact can contain a repeated symbolic stream whose declared alphabet frequencies suggest a compact representation. Arithmetic coding assigns an interval to the whole sequence rather than a separate bit string to each symbol. This lesson examines exact interval semantics before any practical compression or serializer integration. The frequency table is part of the decoding contract.

Partition the current half-open interval according to the ordered cumulative symbol frequencies. Select the subinterval for the next symbol and repeat using both endpoints from the previous step. Exact rational arithmetic prevents rounded boundaries from silently admitting a different symbol. The left endpoint is included and the right endpoint excluded, so a tag exactly on a boundary has a declared owner.

The fixed sequence and its control share a prefix, then finish in different nonoverlapping intervals. A tag inside each final interval decodes the corresponding sequence when the decoder knows its length. Tag representation cost, termination symbols, renormalization and finite precision are outside this small model. Interval width alone is not a measured compressed file size. Preserve alphabet order, frequencies and length before proposing a composable coding stage: a numerical tag without those premises is not a self-describing artifact.
