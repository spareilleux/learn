An agent handoff compresses status symbols into short bit strings. Both ends select the same codebook, and the transmitted bits arrive intact. The receiving agent can still be unable to tell where one symbol ends and the next begins. Agreement on meaning and integrity of bytes do not by themselves establish a uniquely decodable symbol sequence.

Write the codeword beside every symbol before concatenating anything. A prefix-free codebook has no codeword that starts another complete codeword. A left-to-right decoder can therefore finish a symbol without waiting for an unseen separator. For the fixed codebook, trace the supplied bit stream and retain the boundary positions. This is an elementary argument about the declared finite mapping, not an implementation of an internet compression protocol.

The control supplies an explicit ambiguous stream. It can name one symbol or a pair of symbols, both consuming all bits. Stopping at the first plausible parse would hide the ambiguity. Enumerate every complete parse before reporting a unique decoding. A prefix violation is a useful warning, but some non-prefix codes remain uniquely decodable; do not replace a sufficient condition with an unsupported equivalence.

RFC HPACK describes concatenated Huffman codes with their own framing and padding requirements. Our toy mapping borrows the communication question, not its wire format or code table. The prior lessons retain codebook versions and byte lengths; this operation concerns boundaries inside a concatenated code stream. A future DSL shorthand must make separators, lengths or a decoding convention explicit. The direct manual baseline is small enough to examine every alternative without creating a transport service.

### Exercise 1

Decode the fixed stream completely.

<details><summary>Answer 1</summary>

The only complete sequence is `[A,B,C]`. Its boundaries follow the codewords `0`, `10`, `11`; no other symbol sequence consumes the stream.

</details>

### Exercise 2

Identify the control’s prefix violation.

<details><summary>Answer 2</summary>

Symbol `A` is a proper prefix of `B`. The ordered violation list is `[[A,B]]`; the codebook is not prefix-free.

</details>

### Exercise 3

Exhibit both complete control parses.

<details><summary>Answer 3</summary>

Stream `01` decodes as `[A,C]` or `[B]`, giving `2` complete parses. Both must remain visible; choosing the preferred verdict would invent information.

</details>

### Exercise 4

Does every prefix violation prove ambiguous decoding?

<details><summary>Answer 4</summary>

No. Prefix-free is a sufficient immediate-decoding property. For this control, ambiguity is established by the actual colliding sequences, not by an overgeneralized converse.

</details>

### Exercise 5

Would a byte checksum solve this ambiguity?

<details><summary>Answer 5</summary>

No. Both interpretations use the same intact bits. Specify symbol boundaries or a suitable code before discussing integrity checks; those checks address a different failure.

</details>
