## Project operation and interpretation

A scene-review agent keeps only captures that look unusual because either a mesh change or a lighting change is present. Inside that selected collection, it notices that mesh changes accompany fewer lighting changes and suggests a compensating causal relationship. The full authored table has independent factors. This course asks what the retention rule itself contributes before attributing the conditional association to the sculpture or renderer.

The shared selection outcome is a collider in the proposed graph: both factors can cause retention. The paper abstract explains why conditioning on such a common effect can introduce an association. Our finite construction makes the mechanism inspectable without fitting a regression or borrowing its medical observations. Among retained cases with no mesh change, a lighting change is necessary to enter the collection. Among retained cases with a mesh change, lighting may be present or absent. The resulting difference is a property of the selection rule.

The all-rows control retains the same original masses and changes only selection. It restores the baseline conditional rates. An actual craft-to-scene comparison should therefore retain the capture-inclusion rule and rejected cases alongside each image, including quiet or unsuccessful captures. An assistant should ask whether inclusion was decided after seeing both factors. The calculation does not prove that a real review dataset contains this bias; it supplies a specific alternative explanation and the evidence needed to investigate it.

### Exercise 1

Compute the unselected conditional rates.

<details><summary>Answer 1</summary>

Both are `0.5`, so the unselected difference is `0`. The authored table makes the factors independent before retention.

</details>

### Exercise 2

Apply the shared-outcome selection.

<details><summary>Answer 2</summary>

Retained mass is `3`. Only the row where both factors are absent is removed; the original weights are otherwise preserved.

</details>

### Exercise 3

Derive the selected association.

<details><summary>Answer 3</summary>

The rates are `1` without a mesh change and `0.5` with one, producing difference `-0.5`. This does not establish compensation.

</details>

### Exercise 4

Apply the all-rows control.

<details><summary>Answer 4</summary>

Retained mass becomes `4` and the difference returns to `0`. Neither the mesh values nor the lighting values were changed.

</details>

### Exercise 5

Which evidence should a scene report retain?

<details><summary>Answer 5</summary>

The inclusion rule and excluded cases, with factor labels and source-bound captures. A selected association alone cannot identify its causal explanation.

</details>
