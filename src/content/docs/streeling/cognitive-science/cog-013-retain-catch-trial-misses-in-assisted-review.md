> This lesson uses an authored fixed case and inspected sources. Counts, times, labels and signals are invented teaching inputs. Human technical review, fluent-language review, actual learner attempts, runtime execution, production adoption and publication decisions remain undecided.

A dogfood report says an assistant made review easier because more tasks were completed. Completion can coexist with accepting the assistant’s wrong suggestion. The aided-success prerequisite separates modes of assistance; the order prerequisite addresses sequence effects. This lesson chooses catch items with deliberately wrong suggestions and retains which errors a reviewer misses in each mode. It asks about oversight at an explicit boundary rather than general learning.

The external key must be established before presenting an item. A miss means accepting the planted wrong suggestion, with the same definition in both conditions. Pair the outcomes by item identity before subtracting totals. The items missed only with assistance identify concrete explanations to inspect; the items missed in both modes may reveal a different difficulty. An average difference alone loses this diagnostic distinction.

[NIST](https://www.itl.nist.gov/div898/handbook/pri/section3/pri332.htm)’s discussion of blocks motivates comparing conditions within controlled nuisance groups. Our invented paired vectors are an accounting example, not an actual randomized block experiment. Exposure to an item can teach its answer, and seeing a wrong suggestion can influence a later manual judgment. A real design therefore needs suitable parallel items or justified assignment and order controls before a causal assistance claim is credible.

The retained project observations explicitly leave quiz or study implementation unset and show no learner-answer events in the selected source. They cannot be repurposed as the paired observations below. A proposed agent evaluation card should keep item key, original suggestion, response and assistance mode. The direct manual baseline is the paired table, including negative results. Neither an easier feeling nor an improved completion count supplies the missing catch-item evidence.

Both conditions inspect the same proposed answer and source key. The manual condition receives no assistant endorsement; the assisted condition additionally sees an endorsement of that proposed answer. These are stipulated presentation conditions for the model, not actual participant exposures.

### Exercise 1

Compute both miss rates under the stated miss definition.

<details><summary>Answer 1</summary>

The manual miss rate is `0.25`; the assisted miss rate is `0.75`. A miss records acceptance of the planted wrong answer. These are authored response vectors, not observations of real reviewers.

</details>

### Exercise 2

Calculate paired excess and name the discordant items.

<details><summary>Answer 2</summary>

Paired excess is `0.5`. Items `b` and `c` are assisted-only misses, while there are no manual-only misses. Keep their identities so the actual reasoning could later be inspected.

</details>

### Exercise 3

Apply the matched-vector control. Does a copied vector become another reviewer?

<details><summary>Answer 3</summary>

Both miss rates become `0.25` and excess becomes `0`. There are no discordant items. Copying is a mathematical control; it does not create independent review or a real second condition.

</details>

### Exercise 4

Can the main difference prove that assistance causes complacency?

<details><summary>Answer 4</summary>

No. The data are invented, and order, familiarity, item equivalence and assignment have not been observed. The calculation identifies a possible oversight signal without diagnosing its psychological cause.

</details>

### Exercise 5

What must a real dogfood record preserve before a correction is revealed?

<details><summary>Answer 5</summary>

Retain the original suggestion, keyed error, reviewer answer, item identity, mode, order and other assistance. Keep the initial miss before the corrected response; replacing it with the final answer would erase the event being evaluated.

</details>

## Source-assisted learner task

Start with a paper table before revealing the answers. Copy the inputs and their units, apply the declared operation, and retain intermediate results. This direct calculation is the manual baseline against which an assistant or a proposed composable notation must be compared. A shorter response has no demonstrated advantage if it loses an input identity, a failure category or the counterexample.

Then inspect the precise source passage recorded in the packet. Quote only the small field or branch needed for your explanation and record its revision. Ask an assistant to challenge one assumption after you have saved your first answer. Retain the prompt, reply, accepted corrections and rejected suggestions. Source lookup and calculator use are allowed; record them as assistance so the result cannot be mistaken for unaided recall.

Apply the changed input in the negative control and state an observable falsifier before making a recommendation. An unexpected control result requires checking the calculation and assumptions before changing a project workflow. Submit the original answer, corrected answer, assistance history and remaining uncertainty together. The packet prepares five learner criteria, one per exercise, with undecided decisions. Prepared solutions and author checks do not fill those decisions. A future dogfood comparison needs actual attempts on the same task and a retained manual baseline; no new agent mechanism or DSL implementation is required by this lesson.
