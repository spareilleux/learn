> This lesson uses authored fixed inputs and inspected source passages. The numbers, histories and labels are teaching constructions. Human technical review, fluent-language review, learner attempts, runtime execution, production adoption and publication decisions remain undecided.

A review assistant is evaluated on a defect-rich exercise and then applied to mostly clean Learn sources. Its precision need not survive that move even if its hit rate and false-alarm rate do. The earlier lesson separates those conditional rates; this lesson rebuilds the mixture that a project user would actually see.

Google’s metric definitions put true positives over all alerts for precision. To use that denominator prospectively, first split the authored population into defective and clean items, then apply the appropriate response rate to each group. The resulting counts are expectations under the model, not a new observed confusion matrix.

The premise that both conditional rates remain unchanged is substantive. New defect types, reviewers, thresholds or source formats can break it. A correct recalculation cannot establish transportability from arithmetic alone. Keep prevalence, response rates and their provenance as separate fields in any proposed evidence DSL. A headline precision copied from a balanced exercise would silently import its task mixture.

### Exercise 1

Compute expected true and false alerts.

<details><summary>Answer 1</summary>

There are `80` true positives and `90` false positives, for `170` alerts. Each rate uses its own true-class denominator.

</details>

### Exercise 2

Compute precision in the fixed case.

<details><summary>Answer 2</summary>

`80/170=0.47058823529411764`. Precision concerns the composition of alerts, not the fraction of defects detected.

</details>

### Exercise 3

Apply the higher-prevalence control.

<details><summary>Answer 3</summary>

Expected counts become `400` true positives and `50` false positives, totaling `450`; precision is `0.8888888888888888`.

</details>

### Exercise 4

Did the control improve the reviewer’s conditional rates?

<details><summary>Answer 4</summary>

No. The rates are unchanged; the population mix changed. Calling this a skill improvement would misattribute the construction.

</details>

### Exercise 5

What could invalidate the transported estimate?

<details><summary>Answer 5</summary>

A changed threshold or different conditional behavior invalidates the premise. Actual task data are needed; the source definition does not supply those rates.

</details>
