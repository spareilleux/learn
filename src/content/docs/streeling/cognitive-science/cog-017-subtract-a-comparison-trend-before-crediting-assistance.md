An assisted group improves after a Learn workflow change. A separate comparison group also improves. Reporting only the assisted change ignores a possible common trend. The counterfactual prerequisite shows why a before-after difference alone cannot identify benefit; this lesson supplies one particular comparison and names its additional assumption.

The World Bank’s canonical discussion subtracts the comparison group’s change from the treated group’s change. Its causal interpretation requires parallel trends in the untreated outcomes. That is not the claim that the observed groups have identical initial levels. Nor can a single earlier measurement prove what either group would have done later without assistance.

Work in proportions and keep group identities fixed. First retain both changes, then their contrast. The control gives both groups the same change while leaving a favorable assisted before-after story intact. A proposed agent report should include that counterexample before crediting the workflow. Actual participants, comparable tasks and a justified design remain absent from this authored table.

## Fixed model and control

```json
{
  "values": {
    "assisted_before": 0.4,
    "assisted_after": 0.7,
    "comparison_before": 0.5,
    "comparison_after": 0.6
  },
  "formula": "assisted_change=after-before; comparison_change=after-before; contrast=assisted_change-comparison_change.",
  "expected": {
    "assisted_change": 0.3,
    "comparison_change": 0.1,
    "contrast": 0.2
  },
  "negative_control": {
    "values": {
      "assisted_before": 0.4,
      "assisted_after": 0.7,
      "comparison_before": 0.5,
      "comparison_after": 0.8
    },
    "expected": {
      "assisted_change": 0.3,
      "comparison_change": 0.3,
      "contrast": 0
    },
    "why": "Equal group changes erase the differential despite assisted before-after improvement."
  },
  "assumptions": [
    "Comparable endpoints and stable group composition; no interference.",
    "A causal reading additionally requires parallel untreated trends and no differential concurrent change."
  ],
  "limits": "Arithmetic contrast is descriptive; two periods cannot establish parallel trends, randomization or learner benefit.",
  "input_types": {
    "assisted_before": "proportion",
    "assisted_after": "proportion",
    "comparison_before": "proportion",
    "comparison_after": "proportion"
  }
}
```

### Exercise 1

Compute the assisted change.

<details><summary>Answer 1</summary>

`0.7-0.4=0.3`. It describes the supplied group’s change, not an identified intervention effect.

</details>

### Exercise 2

Compute comparison change and the contrast.

<details><summary>Answer 2</summary>

`0.6-0.5=0.1`, so the contrast is `0.3-0.1=0.2`. Both changes must retain the same subtraction direction.

</details>

### Exercise 3

Apply the equal-trend control.

<details><summary>Answer 3</summary>

The comparison change becomes `0.8-0.5=0.3`; the contrast is `0`. Assisted improvement alone persists.

</details>

### Exercise 4

Does a different initial level refute parallel trends?

<details><summary>Answer 4</summary>

No. The assumption concerns changes in untreated potential outcomes, not equal starting levels. It remains unverified here.

</details>

### Exercise 5

What prevents a causal claim from these numbers alone?

<details><summary>Answer 5</summary>

Unobserved untreated trends, changing group composition or concurrent changes could alter interpretation. The arithmetic does not observe those counterfactuals.

</details>
