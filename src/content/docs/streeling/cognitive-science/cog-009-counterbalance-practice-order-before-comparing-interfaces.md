A GA practice interface appears faster after an agent redesigns its prompts. But the learner always sees the old interface first. Could familiarity explain some of the difference? The assistance prerequisite identifies eligible responses. This course adds another eligibility question: which comparison design can distinguish an interface difference from a stipulated practice-order effect? All times below are fictional deterministic values, not observed learners.

NIST's design guidance explains why a nuisance factor should be tracked and controlled. We use period as a declared nuisance factor and place each interface in each period with equal weight. This balanced teaching construction is not a claim that order reversal alone removes every human carryover effect. The model assumes a common additive benefit in the later period and no interface-specific learning. Those assumptions are precisely what a real pilot would need to challenge.

In the forward order, the later interface combines its base advantage with the period benefit. In the reverse order, those contributions offset in the within-order contrast. Keep the contrast direction fixed as the later-named interface minus the earlier-named interface identity, regardless of presentation order. Otherwise changing the subtraction direction would manufacture cancellation. Lower seconds mean faster completion for this endpoint; they do not establish better learning or fewer mistakes.

Average the two order contrasts with equal weights. Under the stipulated additive model the period term cancels and the remaining difference equals the base interface contrast. The negative control gives the interfaces identical base times. It should retain opposite order effects and no balanced interface difference. A report that finds a base advantage in that control has mixed up order, weights or direction.

For the source-assisted task, read the prerequisite's assistance table and the NIST nuisance-factor definition. Draft an answer-free comparison card for a GA fretboard task: define timing endpoints, eligibility, error reporting and order assignment before any participant attempt. The direct baseline is a paper allocation table. Ask an assistant to critique carryover and unequal task difficulty. Reject a redesign claim if it relies only on the forward order or silently treats these invented seconds as measured user performance.
