A practice score can say how many answers matched the key while hiding which interval a guitarist confuses with another. That distinction affects the next useful question GA should ask. We construct a small confusion table whose row and column conventions remain explicit. The purpose is diagnosis of an authored answer pattern, rather than proof that a learner improved. The prerequisite established when an attempt passes; this lesson preserves the type and direction of mistakes before proposing practice.

### Exercise 1

Rows are true labels and columns are answers, both ordered `[major,minor]`. Counts are `[[3,1],[2,4]]`. The top-right entry means a true major item answered minor; the bottom-left means the opposite. Writing the orientation beside the table prevents an agent from reversing the diagnosis while preserving all the same printed numbers.

How many errors occur in each direction?

<details><summary>Answer 1</summary>

There is `1` major-to-minor error and `2` minor-to-major errors. The counts describe answer direction under the declared row/column convention.

</details>

### Exercise 2

The table contains `10` trials, and diagonal counts sum to `7`. Accuracy is `7/10=0.7`. This denominator includes all declared complete trials. Missing answers, retries and hinted attempts would need separate fields; none is silently included here. The scalar result is useful for a summary but loses the distinction between the two error directions.

What are total trials, correct answers and accuracy?

<details><summary>Answer 2</summary>

They are `10`, `7` and `0.7`. These are synthetic descriptive quantities, not evidence of an observed learning gain.

</details>

### Exercise 3

True major items total `4`, giving recall `3/4=0.75`. True minor items total `6`, giving recall `4/6=2/3`. Always answering the more frequent true class would score `6/10=0.6` on this authored table. The classifier's accuracy exceeds that local baseline, but the comparison alone establishes neither transferable skill nor a causal benefit from practice.

Which class has lower recall and what is the majority baseline?

<details><summary>Answer 3</summary>

Minor has lower recall, `2/3`, compared with `0.75` for major. The majority-answer baseline is `0.6`; it depends on the table's unequal class totals.

</details>

### Exercise 4

The negative control swaps response-column meanings, producing `[[1,3],[4,2]]`. Trial totals remain `10`, but correctness becomes `3` and accuracy `0.3`. An auditor checking only count preservation would miss a corrupted answer-label map. Preserve labels and mapping revision with any agent-generated diagnostic, rather than treating a matrix image as self-explanatory.

What changes after swapping the answer labels?

<details><summary>Answer 4</summary>

Accuracy becomes `0.3`, with recalls `[0.25,1/3]`. The same trial total cannot certify correct interpretation of the response columns.

</details>

### Exercise 5

A useful next practice proposal might target the more frequent confusion while balancing future test items and withholding answer cues. That is a proposal whose value needs later evidence. Repeating the exact original sounds may test memory for examples rather than interval transfer. Keep original answers before feedback, assistance and novel-item conditions if a future claim concerns learning.

What would falsify a diagnostic claiming to preserve error direction?

<details><summary>Answer 5</summary>

A report that exchanges the two off-diagonal meanings or gives unchanged accuracy for the swapped-label control contradicts the declared table. An improved future score would still need comparable conditions before supporting a learning claim.

</details>
