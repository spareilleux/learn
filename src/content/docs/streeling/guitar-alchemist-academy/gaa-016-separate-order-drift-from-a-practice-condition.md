A guitarist may improve through a short session even when two instruction formats have identical effects. Assigning one format later can make its average look better. For a [GA](https://github.com/GuitarAlchemist/ga) practice comparison, inspect trial order as well as factor balance. We construct a linear drift and compare two schedules with the same number of trials per condition.

## Read the retained evidence

The design source discusses randomized run sequence and balanced replication. Our symmetric schedule is deterministic and therefore is not a randomized experiment. The retained practice rules define responses; they do not remove temporal dependence.

## Preserve the temporal nuisance hypothesis

Equal counts make the condition averages easy to compare, but do not determine which times contribute to those averages. Under a linear nuisance trend, average trial position becomes the relevant additional quantity. The symmetric order makes that position equal across conditions. This is an algebraic cancellation for the chosen trend, not a general guarantee that order no longer matters.

The alternative schedule illustrates why inspecting only a marginal count table is insufficient. It contains the same labels, counts and response sequence, yet associates later positions with one condition. A summary that discards order before analysis cannot reconstruct that association afterward. The raw trial ledger therefore needs to survive any dashboard aggregation, along with the scoring rubric and which format was actually delivered.

There are plausible trends this schedule does not cancel. Abrupt learning after feedback, a pause halfway through the session or a carryover effect from the preceding format can change the response outside the linear model. A future experiment should decide how to randomize, block or model those possibilities before observing outcomes. The direct mean-position calculation helps choose that next design step. Adding an agent to shuffle labels does not by itself document randomization, retained stimulus delivery or an unbiased learning comparison; those claims need their own recorded procedure and observations.

### Exercise 2

Compute the main condition means. Why does this order cancel the selected trend?

<details><summary>Answer 2</summary>

Each condition’s average trial position is the same. Therefore this particular linear drift contributes the same amount to both means.

</details>

### Exercise 3

Does a zero main contrast prove the conditions equivalent for musicians?

<details><summary>Answer 3</summary>

No. It is an exact result of an authored nuisance model. Real outcomes, uncertainty, carryover and musical relevance were not observed.

</details>

### Exercise 4

Apply the alternating-order control. Does equal replication remove its spurious contrast?

<details><summary>Answer 4</summary>

No. The later average position of the second condition produces the displayed nonzero contrast despite equal trial counts and no stipulated treatment effect.

</details>

### Exercise 5

What rejects a claim that marginal balance controls every order effect?

<details><summary>Answer 5</summary>

The control already supplies a linear-drift counterexample. Nonlinear drift could also defeat the symmetric schedule; retain order and test that assumption before interpreting a real comparison.

</details>
