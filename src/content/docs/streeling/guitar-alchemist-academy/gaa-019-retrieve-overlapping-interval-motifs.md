A GA practice search finds the right collection of intervals but misses that a learner’s short motif occurs repeatedly inside a phrase. The collection does not preserve contiguity, ordering or multiplicity of occurrences. We scan a directed interval stream for an exact short pattern and retain overlapping matches. This adds a sequence-retrieval operation beyond the prerequisite’s transposition exercise.

A motif occurrence begins at an interval index, not necessarily a note index under every representation. Declare the convention and compare each candidate slice with the complete motif. After a match, advance only to the next possible start; skipping the whole matched length would discard overlapping occurrences in this case. Retaining start positions allows a reviewer to recover which parts of the source phrase were selected. A count alone would lose that correspondence.

The control rearranges the same interval multiset and removes every contiguous occurrence. Any retrieval strategy that treats the streams as identical because their interval counts agree cannot satisfy this task. Conversely, exact interval matching ignores rhythm, phrasing and register; it should not be advertised as general musical-theme recognition. ## Assumptions and evidence limits

Assume exact directed integer semitone intervals and contiguous matching, allowing overlaps. Starts use zero-based interval indices. Rhythm, register, musical theme identity and approximate retrieval are outside this endpoint.
