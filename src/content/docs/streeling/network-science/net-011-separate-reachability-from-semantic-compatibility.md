A tool catalog contains a path from capture through analysis to display. The receiving node accepts the array length and draws an image. Has the pipeline composed correctly? A reachable graph path says that edges exist under a chosen definition. It does not guarantee that the payload's coordinates and scale mean what the consumer expects. The prerequisites supply both the catalog boundary and the concrete spectral context.

Read IX's path-search operation as a structural question. Then read the spectral lesson's frame-major discussion. Our fixed producer and consumer records have matching shapes and sample rates, yet disagree on orientation and scale. These records are authored contract cards rather than a new API schema. They are intentionally small enough that a learner can compare every field without running a service.

Shape equality does not prove orientation equality. A consumer may interpret stored positions differently while reading the same number of cells. Similarly, linear and logarithmic values cannot be silently exchanged because both happen to be numeric. A real conversion would need its reference, handling of zero and precise semantics. This lesson does not supply that conversion or claim that renaming a field performs it.

The compatibility rule is a conjunction over the declared teaching fields. Report each mismatch instead of collapsing everything into a transport failure. A disconnected path and an incompatible payload need different repairs. A matching contract still leaves runtime availability, authentication, actual implementation identity and result evidence open. Those concerns are not secretly represented by a green edge in this graph.

For the source-assisted task, annotate the catalog prerequisite's definition of an edge and the spectral prerequisite's orientation sentinel. Draw the route manually and compare the contract cards field by field. Then ask an assistant to identify the minimal mismatch set and propose evidence for an adapter, without implementing one. The negative control changes the consumer to match the producer. Reject a composition claim if it uses path existence or total cell count as its only evidence of semantic compatibility.
