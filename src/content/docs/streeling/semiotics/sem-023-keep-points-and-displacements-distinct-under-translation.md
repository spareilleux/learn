## Project operation and interpretation

A craft DSL uses identical numeric arrays for a position and a displacement, then translates both by the frame origin. Units cannot detect that mistake: both carry length units, but only points receive the origin. With the identity basis, translate both points and subtract them to obtain the unchanged displacement. Keep the affine role with the value before composition. This isolates translation from rotation and scaling and adds no scene adapter. A displacement is not a normal, and a valid difference calculation does not verify an asset import or a physical measurement.
