## Project question

A future craft renderer migration removes the old path immediately. A staged alternative retains it until an acceptance gate passes. Which plan limits regret if the candidate is unsuitable? The older BRUTAL record contains a coexistence failure and an inconclusive follow-up; it does not provide a success probability for this decision. This lesson compares conditional loss by scenario and makes rollback availability explicit without inventing a live pilot.

## Read the boundary before calculating

Read the linked prerequisite and project record before doing the arithmetic. Identify which statement comes from inspected source, which is an older recorded result, and which follows only from the premises below. A source comment, a prepared answer and an executed observation have different evidential roles. Preserve the original date and any failed or inconclusive gate when summarizing an older artifact. The direct baseline is a small handwritten calculation and a source-location table; an agent may help locate a definition, but its summary must be checked against that definition. Do not introduce a new language or automation merely to perform this finite comparison.

Use two authored states, suitable and unsuitable, and comparable loss points. A direct migration has lower cost when suitable but greater loss when unsuitable. Staging costs more in the favorable state because it maintains two paths and checks a gate. In the unsuitable state it preserves an exit. Compare worst-case losses and scenario regret before invoking probabilities. This differs from the prerequisite’s expected value of information: we do not estimate likelihoods or average states. A faulty gate can admit the unsuitable candidate and erase the supposed protection. Rollback is a property requiring an actual retained artifact and compatibility path, not a reassuring word in a plan.

## Corrected exercises

### Exercise 1

Which plan has the lower loss in each state?

> **Answer:** Direct wins when suitable with `6` versus `10`; staging wins when unsuitable with `8` versus `26`. Neither plan dominates both states.

### Exercise 2

Compare worst-case losses.

> **Answer:** They are `26` for direct and `10` for staged. A worst-loss preference favors staged under this authored table, without establishing real probabilities.

### Exercise 3

Derive both regret vectors.

> **Answer:** Subtract the best loss in each state: direct gives `[0,18]`, staged `[4,0]`. Their maximum regrets are `18` and `4`.

### Exercise 4

Apply the faulty-gate control. Does staging remain automatically safer?

> **Answer:** No. Its worst loss becomes `30`, exceeding direct’s `26`. The correct-gate premise is material, not a guaranteed property of staging.

### Exercise 5

May the old inconclusive renderer report authorize migration?

> **Answer:** No. It preserves unresolved coexistence evidence. A real plan needs source-bound acceptance, retained rollback artifacts and applicable authorization; this loss table supplies none of those observations.
