Two agent stages write different output files, so a coordinator proposes running them in either order. The report stage also reads the manifest written by the first stage. Different destinations alone do not establish independence. A footprint must include inputs as well as outputs.

SQLite’s isolation guide distinguishes separate connections and serialized writes. Its actual guarantees belong to that database. Here we declare a smaller static contract for fictional Learn stages: each resource name identifies one mutable location, reads do not mutate, and the footprints are complete. Compare each stage’s writes with everything the other stage touches. Shared reads are harmless under these assumptions; any overlap involving a write requires preserving or justifying order.

The check deliberately rejects some stages that might commute by a deeper argument. Both could set the same constant, for example. A conflict is a reason this sufficient test cannot justify reordering, not proof that every execution differs. Hidden state invalidates a favorable result, so a proposed DSL must expose effects rather than merely wrapping commands in parallel notation.

### Exercise 1

Find the fixed-case conflict.

<details><summary>Answer 1</summary>

`manifest` belongs to the first write set and second read set. The conflict list is `[manifest]`, so `independent=false`.

</details>

### Exercise 2

Why do different output files not suffice?

<details><summary>Answer 2</summary>

The second stage consumes a value the first changes. Reversing them can read an older manifest even though their write sets are disjoint.

</details>

### Exercise 3

Apply the shared-read control.

<details><summary>Answer 3</summary>

Both stages read `source`, while writing different resources. The conflict list is `[]` and `independent=true` under complete footprints.

</details>

### Exercise 4

Does a conflict prove noncommutativity?

<details><summary>Answer 4</summary>

No. This is a sufficient independence test. A separate argument could show equal behavior despite an overlap, but the footprint alone cannot.

</details>

### Exercise 5

Name a falsifying hidden effect.

<details><summary>Answer 5</summary>

An unlisted write to a shared cache invalidates the completeness premise. Retain it and recompute; do not call an incomplete empty intersection a safety proof.

</details>
