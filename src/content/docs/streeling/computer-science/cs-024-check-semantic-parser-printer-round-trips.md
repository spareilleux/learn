A GA explanation agent may rewrite a small expression to make it easier to read before handing it to an IX pipeline author. A visually tidy result can silently change grouping. Conversely, a printer can preserve every operation while changing whitespace. The useful question is which representation must survive the handoff. Establish that contract before comparing strings or advertising a DSL simplification.

Here the source language has integer literals, addition, multiplication and parentheses. Parse the source into an ordered tree, print a candidate, and parse the candidate again under the same grammar. Compare the trees recursively. The Python AST documentation supplies a concrete precedent for an equivalent-tree promise without an identical-text promise. We borrow that distinction; this toy grammar is neither Python nor a new GA parser.

The fixed case retains multiplication inside the right child of addition. Its result agrees after rewriting, although the source strings differ. Numerical agreement alone would be weaker evidence: two different trees might coincidentally produce the same number on one input. The control deliberately moves addition beneath multiplication, changing both structure and result. Preserve the first differing node as the useful diagnostic.

Before proposing a formatter or agent rewrite, choose whether comments, spelling and layout are part of the product requirement. A syntax tree that omits those details cannot reconstruct them. The lexical-binding prerequisite addresses a different failure involving names; our name-free grammar isolates precedence. A future richer grammar would need both checks. The direct task is a paper tree comparison with a falsifier, not permission to replace the production parser.

The semiotics prerequisite already traces GA parsing and canonical rendering, including many-to-one aliases. Canonicalization itself is prior art. The extra check here reparses the printed expression and compares its full ordered tree, with a changed-grouping witness that rejects a false round-trip law.

### Exercise 1

What is the source tree?

<details><summary>Answer 1</summary>

Its root is `add`, with left child `lit(1)` and right child `mul(lit(2),lit(3))`. Multiplication binds first; the source evaluates to `7`.

</details>

### Exercise 2

Does the fixed printer preserve the contract?

<details><summary>Answer 2</summary>

Yes: the parsed trees agree and both values are `7`, while text equality is `false`. A whitespace difference is permitted by this semantic contract.

</details>

### Exercise 3

Evaluate the changed grouping.

<details><summary>Answer 3</summary>

The control has root `mul` and value `9`. Its differing tree is a counterexample to the proposed round-trip guarantee, regardless of its attractive formatting.

</details>

### Exercise 4

Would one equal value prove tree equality?

<details><summary>Answer 4</summary>

No. Distinct operations can coincide on selected inputs. Preserve node tags and ordered children, and state separately whether comments and layout need a lossless representation.

</details>

### Exercise 5

What evidence would justify using an agent rewrite?

<details><summary>Answer 5</summary>

A versioned grammar, the manual trees, the rejected grouping and coverage of relevant syntax. This case supports only its declared expressions; it supplies no production parser execution.

</details>

## Source-assisted learner task

Annotate an agent-proposed expression rewrite for a GA-to-IX explanatory handoff.

**Direct manual baseline:** Draw both ordered trees by hand and locate their first differing node.

**Falsifier:** A candidate claimed to preserve the tree changes a node tag or child grouping.

Save a first answer before opening the solutions. Identify the input types, the comparison boundary and the quantity that the task asks you to preserve.
