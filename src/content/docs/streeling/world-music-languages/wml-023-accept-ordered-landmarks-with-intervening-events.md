A teaching phrase may require ordered landmarks while allowing ornamental events between them. Contiguous substring search is too strict for that declared contract, while unordered membership is too permissive. Advance the next required landmark only when its label is encountered; preserve the accepted source indices as a witness. Repeated landmarks require separate later events. The policy is deliberately authored for a [GA](https://github.com/GuitarAlchemist/ga) exercise. It does not define any tradition’s ornamentation, judge style or infer which extra notes a musician would consider acceptable.

## Specific assumptions and limits

The finite event scan consumes each event at most once and freely ignores extra labels under the stipulated policy. Repeated required labels need distinct later events. No stylistic judgment, timing tolerance or performance recognizer is supplied.

## Fixed case and prepared quantities

```json
{
  "values": {
    "landmarks": [
      "a",
      "c",
      "e"
    ],
    "events": [
      "a",
      "b",
      "c",
      "d",
      "e"
    ]
  },
  "formula": "scan events left to right; advance next landmark on equality; witness stores consumed event indices; accepted iff all landmarks consumed",
  "expected": {
    "witness": [
      0,
      2,
      4
    ],
    "consumed": 3,
    "accepted": true
  },
  "negative_control": {
    "values": {
      "landmarks": [
        "a",
        "c",
        "e"
      ],
      "events": [
        "e",
        "b",
        "c",
        "d",
        "a"
      ]
    },
    "expected": {
      "witness": [
        4
      ],
      "consumed": 1,
      "accepted": false
    }
  }
}
```

### Exercise 1

Calculate the main result and name its convention.

> **Answer:** The witness is `[0,2,4]`, so all 3 landmarks are consumed despite intervening events.

### Exercise 2

Which quantity must remain separate?

> **Answer:** Ordered subsequence differs from contiguous motif and from unordered membership.

### Exercise 3

What assumption prevents a stronger conclusion?

> **Answer:** Ignoring all extra labels is a stipulated policy, not a musician’s judgment about acceptable ornament.

### Exercise 4

Explain the negative control.

> **Answer:** The reversed-order control consumes only index 4 and fails, despite containing the same landmark labels.

### Exercise 5

What observation would reject the proposed claim?

> **Answer:** An accepted record without a strictly increasing complete witness rejects the ordered-landmark claim.
