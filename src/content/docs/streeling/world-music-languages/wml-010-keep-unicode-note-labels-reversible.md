## The project question

A GA handoff replaces a musical sharp sign with an ASCII number sign and later claims to reproduce the original text. Even when the intended pitch is unchanged under a declared vocabulary, the original spelling bytes have been lost. We build a bounded reversible receipt, distinguishing a semantic alias rule from Unicode normalization and from a parser's accepted syntax.

## 1. Exercise 1

Declare the two inputs `C♯4` and `C#4`. The musical sign is `U+266F`; the ASCII sign is `U+0023`. These are different characters, even if a chosen interface treats both as a sharp accidental. Visual similarity or equal intended pitch does not establish equal source text.

How many distinct original tokens are present?

> **Answer.** There are 2 distinct originals, distinguished by their accidental characters.

## 2. Exercise 2

Stipulate an alias map that displays both originals as `C#4`. It has two inputs but one distinct output. That is an explicit application policy, not an assertion that a Unicode normalization form performs the substitution. The normalization annex distinguishes formal equivalence operations from arbitrary semantic rewriting.

Is this display map uniquely invertible by itself?

> **Answer.** No. Its single display value cannot identify which original token was supplied.

## 3. Exercise 3

Retain a pair containing the original token and derived display. Restoring from the original field recovers each initial spelling exactly. The display remains available for the destination's declared syntax. Keep the mapping version and convention if interpretation matters; storing an original token does not make an unsupported parser accept it.

What minimal retained data makes these two rows reversible?

> **Answer.** Keep each original alongside its display; original recovery then returns `C♯4` and `C#4` respectively.

## 4. Exercise 4

Delete the original field as a negative control. Both receipts now contain only `C#4`, so there is no evidence for choosing either original. A reverse mapper that always inserts the musical sign changes the originally ASCII row. Semantic correctness under a declared alias rule cannot certify exact textual restoration.

What fails if reverse mapping always emits the musical sharp?

> **Answer.** The ASCII-original row fails exact restoration; display-only data cannot distinguish the two cases.

## 5. Exercise 5

Read the retained naming-convention lesson before treating accidental aliases as a complete pitch vocabulary. Octave, note-name system and unsupported symbols still require explicit handling. The Unicode annex is primary support for normalization concepts, not proof of GA parser behavior. A future parser test must use a pinned implementation and retain actual results.

What may this source-assisted exercise establish?

> **Answer.** Only the two-token receipt's arithmetic count and exact restoration; parser acceptance and fluent terminology review remain unobserved.
