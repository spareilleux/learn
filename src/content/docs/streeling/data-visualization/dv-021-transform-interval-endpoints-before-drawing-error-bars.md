## Project operation and interpretation

A sculpture comparison panel compresses its nonnegative residual axis with a square-root display map. An assistant transforms the central value and then copies the old symmetric error length to both sides. That operation can move the interval endpoints to values the authored evidence never supplied. The question is how to preserve a declared feasible range when changing coordinates, without pretending that this mathematical range is a calibrated confidence interval.

Transport the centre and both endpoints through the same increasing map. Only afterward subtract the display centre to obtain lower and upper extents. A supplied central estimate need not be the interval midpoint in either coordinate system. The main case has unequal raw distances but equal display distances; the control has equal raw distances but unequal display distances. Those opposite patterns prevent a visual symmetry rule from replacing the endpoint calculation.

A future Learn or [Godot](https://docs.godotengine.org/en/4.5/) diagnostic needs the raw interval, transformation identifier, unit and display endpoints together. The original numbers remain available for arithmetic and practical tolerances. An axis transform changes how positions are drawn; it does not change the underlying residual definition, create extra precision or justify an equivalence margin. A source-assisted reviewer should reconstruct each endpoint from the retained raw data before discussing whether the panel helps compare embroidery or metalwork candidates.

## Fixed model and changed-input control

```json
{
  "values": {
    "centre": 4,
    "lower": 1,
    "upper": 9,
    "transform": "sqrt"
  },
  "formula": "display_centre=sqrt(centre); display_lower=sqrt(lower); display_upper=sqrt(upper); lower_extent=display_centre-display_lower; upper_extent=display_upper-display_centre",
  "expected": {
    "display_centre": 2,
    "display_lower": 1,
    "display_upper": 3,
    "lower_extent": 1,
    "upper_extent": 1
  },
  "negative_control": {
    "values": {
      "centre": 4,
      "lower": 0,
      "upper": 8,
      "transform": "sqrt"
    },
    "expected": {
      "display_centre": 2,
      "display_lower": 0,
      "display_upper": 2.8284271247461903,
      "lower_extent": 2,
      "upper_extent": 0.8284271247461903
    }
  }
}
```

### Exercise 1

Transform the supplied centre.

<details><summary>Answer 1</summary>

The display centre is `2`. This transforms the reference value only; it does not determine either interval endpoint.

</details>

### Exercise 2

Transform both main endpoints.

<details><summary>Answer 2</summary>

They become `[1,3]`. Applying the map to the endpoints preserves their ordering because the declared map is increasing on this domain.

</details>

### Exercise 3

Derive the display extents.

<details><summary>Answer 3</summary>

Both extents are `1`, despite unequal raw distances. Compute them by subtraction after transformation, not by transforming a raw error length.

</details>

### Exercise 4

Apply the raw-symmetric control.

<details><summary>Answer 4</summary>

The lower extent is `2` and upper extent `0.8284271247461903`. Raw symmetry does not survive this nonlinear map.

</details>

### Exercise 5

Does the transformed interval establish statistical confidence?

<details><summary>Answer 5</summary>

No. These are stipulated feasible bounds. A confidence interpretation would need a sampling procedure and its own justification, which the axis cannot supply.

</details>
