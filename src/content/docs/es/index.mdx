## Por qué este sitio

Escribo estos cursos primero para mí: explicar un tema es la mejor manera de comprobar que lo has entendido.
Son públicos para que otros puedan aprovecharlos — y corregirme.

<CardGrid>
	<Card title="Misión" icon="rocket">
		Cada curso empieza por *por qué* aprendo el tema y qué quiero ser capaz de hacer al final.
	</Card>
	<Card title="Lecciones" icon="document">
		Lecciones cortas, con comandos reales y ejercicios con solución.
	</Card>
	<Card title="Diario" icon="pencil">
