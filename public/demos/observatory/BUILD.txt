Observatory Web export provenance

Built 2026-09-27 with the official non-.NET Godot 4.6.1-stable Web export
template. Godot renderer: gl_compatibility (WebGL 2). The Web export disables
SSR, SSIL and volumetric fog from the native Forward+ scene. It is separate
from the higher-quality native build and does not use hardware ray tracing.
